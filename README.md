# Тестирование hh.ru · футер

Учебный QA-проект **Haker049**. Объект проверки — нижняя часть главной страницы hh.ru во Владивостоке. Здесь собраны ручные проверки навигации, смены языка и мобильного вида, а также автотесты переходов по ссылкам.

| Проверка | Результат прогона 3 ноября 2026 |
| --- | --- |
| Ручное тестирование | 13 кейсов. 11 прошли, в двух обнаружены расхождения |
| Автотесты на Playwright и TypeScript | 6 из этих 13 кейсов автоматизированы. Все шесть прошли в Chromium |

## Пример из проверки

После переключения на **English** часть футера переходит на английский, но ссылки «Рейтинг работодателей России» и «Пользовательское соглашение» остаются на русском. Результат повторился при двух переключениях. Ожидание полного перевода требует подтверждения у команды.

![В английской версии футера ссылка на пользовательское соглашение остаётся на русском](https://raw.githubusercontent.com/Haker049/Test/qa/hh-footer-manual/manual/hh-footer/screenshots/14-english-untranslated-agreement.png)

Второе замечание относится к странице «Требования к ПО». Переход работает, но в инструкции название браузера написано как «Goolge Chrome». Поэтому автотест перехода проходит, а ручная проверка текста выявляет опечатку.

## Как посмотреть запуск

Для демонстрации подготовлена [ветка с зависимостями и инструкцией](https://github.com/Haker049/Test/tree/qa/hh-footer-playwright). В её корне выполните команды с установленным Node.js 20 или новее:

~~~sh
npm ci
npx playwright install chromium
npm run test:footer -- --headed
~~~
