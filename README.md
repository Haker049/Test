# Автотесты футера hh.ru

Playwright открывает главную страницу Владивостока без авторизации, находит ссылку в футере, нажимает её и проверяет адрес и заголовок открывшейся страницы.

Автоматизированы шесть [ручных кейсов](testcases/footer.md), TC-FT-02–TC-FT-07: о компании, пользовательское соглашение, защита персональных данных, производственный календарь, требования к ПО и безопасный поиск работы. Для локализации и мобильного вида результаты приведены в [ручном протоколе](manual/hh-footer/test-cases.md).

## Запуск

Из корня проекта с установленным Node.js 20 или новее:

~~~sh
npm ci
npx playwright install chromium
npm run test:footer
~~~

Чтобы посмотреть результат каждого теста, выполните `npx playwright show-report`. При ошибке в отчёте будут снимок экрана и запись шагов. Для демонстрации с открытым браузером используйте `npm run test:footer -- --headed`.
